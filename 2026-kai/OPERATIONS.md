# KAI 일정 운영

- 관리자: calendar.html
- 학생: a.html / b.html (로그인 없는 공개 조회, 반별 자료만 로드)
- 관리자는 GitHub course Contents 읽기·쓰기 토큰으로 연결하며 토큰은 탭 메모리에만 보관합니다.
- 변경 후 공유 저장 시 state.json, a.json, b.json, all.ics, a.ics, b.ics를 하나의 커밋으로 갱신합니다. Pages는 main 저장 시 자동 배포합니다.
- 충돌 시 덮어쓰지 않고 저장을 거부합니다.
- 공개 저장소이므로 전체 자료는 공개입니다. 반별 링크는 인증·접근 차단 수단이 아닙니다.
- Google 캘린더는 all.ics URL 구독으로 연결합니다. 단방향이며 Google 재조회 주기에 따라 지연됩니다.
- 1교시 09:30~10:30부터 한 시간 단위이며 4교시(12:30~13:30)는 점심시간입니다.
- 공개 자료에는 학생 이름·연락처 등을 입력하지 마세요.
- 시간표의 ‘시간표 변경·교차 검증’ 또는 관리자 연결 후 수업 카드를 누르면 양쪽 강사·과목·수업 일정에서 교시를 선택해 맞교환합니다. 로그인 전에는 미리보기만 가능합니다.
- 실제 교시별 분 단위 수업 총량이 같으면 맞교환안을 자동 구성합니다. 다르면 부족한 쪽에 추가 수업을 불러옵니다. 같은 날 뒤 교시에 영향을 받는 수업도 추천하며, 필요한 교시만 또는 다른 날짜 수업도 추가해 연쇄 교환할 수 있습니다.
- 양쪽의 시작 슬롯과 교시별 배치를 각각 지정할 수 있습니다. 3시간↔4시간은 추가 1시간 수업을 선택해 4시간↔4시간으로 맞추고, 남는 1시간이 들어갈 날짜·교시를 정합니다. 교시 배치 변경 시 기존 배치와 맞바꿔 중복·누락을 방지하며, 모든 선택 수업은 같은 길이의 슬롯에 한 번씩 배치되어야 합니다.
- 강사만 변경하거나 빈 슬롯을 직접 편집할 때는 ‘강사만 변경 / 직접 슬롯 편집’을 사용합니다.
- 반·강사·강의실의 새 시간 중복은 차단하고, 기존 중복은 별도 표시합니다. 전체 과정의 반별·과목별 교시 증감이 있으면 확인 체크가 필요합니다. 강사 가능일·담당 자격은 별도 확인합니다.
- 변경 사유와 함께 일괄 기록 후 ‘수정·공지 공유 저장’으로 배포합니다. 교시별 이력은 같은 batchId로 연결되며 선택 시 학생 공지에 변경 전후를 함께 기록합니다. 단일 교시 수정·삭제는 변경 창의 해당 버튼을 사용합니다.
- JPG는 23개 수업 묶음 단위로 여러 이미지 저장, 인쇄/PDF는 A4 가로로 페이지 분할합니다.
