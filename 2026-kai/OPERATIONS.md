# KAI 일정 운영

- 공동 편집: calendar.html (링크를 가진 누구나 로그인·관리자 연결 없이 수정·공유 저장 가능)
- 학생: a.html / b.html (로그인 없는 공개 조회, 반별 자료만 로드)
- 공유 저장소: Supabase asea-workspace 프로젝트의 kai_schedule_state. 공개 Edge Function kai-shared-schedule을 통해서만 읽기·저장합니다. GitHub 토큰이나 DB 비밀 키를 브라우저에 제공하지 않습니다.
- 변경·복원·공지 작성 후 자동으로 DB의 시간표·공지·이력이 한 번에 갱신됩니다. 버전 조건부 저장과 kai_schedule_versions 스냅샷을 사용합니다. 학생 화면도 같은 공유 저장소에서 반별 자료를 불러오며 5초 간격으로 새 버전을 확인합니다. 저장할 때 GitHub Pages 재배포는 필요하지 않습니다.
- 충돌 시 덮어쓰지 않고 저장을 거부합니다.
- 공개 저장소이므로 전체 자료는 공개입니다. 반별 링크는 인증·접근 차단 수단이 아닙니다.
- 캘린더 구독은 학생 배포·구독 화면의 새 Edge Function URL(format=ics&class=all/a/b)을 사용합니다. 기존 github.io/*.ics 구독은 새 주소로 다시 등록해야 합니다. 저장소의 JSON/ICS 파일은 이전 기준 자료이며 실시간 공유본은 DB입니다.
- 1교시 09:30~10:30부터 한 시간 단위이며 4교시(12:30~13:30)는 점심시간입니다.
- 공개 자료에는 학생 이름·연락처 등을 입력하지 마세요.
- 시간표의 ‘시간표 변경·교차 검증’ 또는 수업 카드를 누르면 양쪽 강사·과목·수업 일정에서 바꿀 교시를 체크하고 선택 시간 반영을 눌러 맞교환합니다. 같은 수업의 선택 시간은 한 카드로 묶어 표시합니다. 별도 로그인은 필요하지 않습니다.
- 실제 교시별 분 단위 수업 총량이 같으면 맞교환안을 자동 구성합니다. 다르면 부족한 쪽에 추가 수업을 불러옵니다. 같은 날 뒤 교시에 영향을 받는 수업도 추천하며, 다른 날짜의 수업 묶음도 추가해 연쇄 교환할 수 있습니다.
- 교시별 부분 선택을 허용합니다. 3시간↔4시간은 긴 쪽의 바꿀 3개 교시만 선택하거나 부족한 시간을 다른 수업에서 추가합니다. 선택하지 않은 교시는 그대로 유지합니다. 시작 슬롯과 강의실은 카드에서 조정하며, 나뉜 시간도 날짜·교시 범위를 명시해 같은 수업 카드 하나에 표시합니다. 학생 공지는 같은 변경 내용의 연속 교시를 묶어 표시합니다.
- 강사만 변경하거나 빈 슬롯을 직접 편집할 때는 ‘강사만 변경 / 직접 슬롯 편집’을 사용합니다.
- 각 과목의 기존 강의실을 기본값으로 유지합니다. 306호 과목은 다른 일정으로 이동해도 306호이며 상대 과목도 자신의 기존 강의실을 유지합니다. 카드별 강의실을 한 번 수정하면 선택한 교시에 함께 적용하고, ‘기존 강의실로 복원’으로 되돌립니다.
- 강의실 입력 즉시 전체 기존 예약과 변경안의 최종 배치를 함께 비교해 같은 시간 예약 수업을 표시하고 새 충돌이 있으면 기록을 막습니다. 맞교환으로 비워지는 기존 예약은 중복으로 판정하지 않습니다. 강의실 변경도 교시별 변경 이력과 학생 공지에 포함합니다.
- 반·강사·강의실의 새 시간 중복은 화면과 공유 저장 API에서 모두 차단하고, 기존 중복은 별도 표시합니다. 전체 과정의 반별·과목별 교시 증감이 있으면 확인 체크가 필요합니다. 강사 가능일·담당 자격은 별도 확인합니다.
- 변경 사유와 함께 변경하기를 누르면 즉시 자동 저장하고 서버 저장 성공 후 완료 알림을 표시합니다. 교시별 이력은 같은 batchId로 연결되며 선택 시 학생 공지에 변경 전후를 함께 기록합니다. 단일 교시 수정·삭제는 변경 창의 해당 버튼을 사용합니다.
- JPG는 23개 수업 묶음 단위로 여러 이미지 저장, 인쇄/PDF는 A4 가로로 페이지 분할합니다.

- 변경 이력은 batchId별 작업 한 건을 카드 하나로 묶습니다. 기존 일정대로 복원은 이 작업 전체를 되돌리고 복원 이력을 새 작업으로 추가합니다. 이후 수업 수정 또는 새로운 시간·강사·강의실 충돌이 있으면 덮어쓰지 않습니다. 복원도 즉시 자동 저장되며 링크 편집자 누구나 사용할 수 있습니다.
- 통합 일정 상단의 오늘의 일정은 한국 시간 기준으로 A반·B반의 교시, 수업·과목, 강사를 두 줄의 간략한 영역에 표시합니다. 조회 월·기간과 별개로 오늘 자료를 표시합니다.

- 변경하기와 공유 저장 성공 시 완료 팝업을 표시합니다. 변경하기는 서버 저장 성공 후 전체 반영 완료를 안내하며, 실패 시 완료로 표시하지 않습니다.
- 모든 메뉴와 학생 화면의 JPG 저장 옆 이미지 클립보드 복사는 현재 조회 조건·출력 모드를 PNG 한 장으로 복사합니다. 여러 출력 페이지는 세로로 이어 붙입니다. 인쇄 미리보기에서도 선택 출력 모드로 복사할 수 있습니다. 브라우저 클립보드 권한이 필요할 수 있습니다.
- 교수 이름은 화면·선택 목록·개인 일정 제목·출력물에서 교수님 존칭으로 표시합니다. 예: 김현수 교수님 개인 강의 일정표. 실제 teacher 식별 값은 원래 이름을 그대로 유지합니다.

- 미저장 수정본은 localStorage에 원본 버전과 함께 보관하고, 창을 다시 열면 서버 최신 자료에 충돌 없이 병합·재저장합니다. 오프라인에서는 마지막 공유본과 로컬 수정본을 복구하며, 재연결 시 저장합니다. 같은 수업에 상충하는 변경이 있으면 덮어쓰지 않고 수정본 백업을 제공합니다.
- 저장 중 추가한 변경도 순서대로 저장하며, 다른 단말의 독립적인 변경과 누적 이력을 버전 충돌 시 합칩니다. 화면 복귀·온라인 복귀 시에도 최신 공유본을 확인합니다.
- 오늘의 일정은 기존 paper 카드와 같은 글자색·서체·1px 테두리·6px 모서리 스타일을 사용합니다.
