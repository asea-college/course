# KAI 일정 운영

- 관리자: calendar.html
- 학생: a.html / b.html (로그인 없는 공개 조회, 반별 자료만 로드)
- 관리자는 GitHub course Contents 읽기·쓰기 토큰으로 연결하며 토큰은 탭 메모리에만 보관합니다.
- 변경 후 공유 저장 시 state.json, a.json, b.json, all.ics, a.ics, b.ics를 하나의 커밋으로 갱신합니다. Pages는 main 저장 시 자동 배포합니다.
- 충돌 시 덮어쓰지 않고 저장을 거부합니다.
- 공개 저장소이므로 전체 자료는 공개입니다. 반별 링크는 인증·접근 차단 수단이 아닙니다.
- Google 캘린더는 all.ics URL 구독으로 연결합니다. 단방향이며 Google 재조회 주기에 따라 지연됩니다.
- 1교시 09:30~10:30부터 한 시간 단위이며 4교시(12:30~13:30)는 점심시간입니다.
- 공개 자료에는 학생 이름·연락처 등을 입력하지 마세요.
- 수업 카드 묶음의 첫 교시를 수정합니다. 각 교시 수정은 주간 보기에서 선택하세요.
- JPG는 23개 수업 묶음 단위로 여러 이미지 저장, 인쇄/PDF는 A4 가로로 페이지 분할합니다.
